HOW TO VIEW YOUR SITE ON GITHUB PAGES
=======================================

Since Hostinger is currently giving an error, you can use GitHub Pages to view a "static" version of your site. 
Note: The database features (Login, Announcements, Events) will NOT work on GitHub, but you will see the design and layout.

INSTRUCTIONS:
1. Go to your repository settings:
   https://github.com/Nathaniel-Owusu/mission-hope-ghana/settings/pages

2. Under the "Build and deployment" section > "Source", select "Deploy from a branch".

3. Under "Branch", select "main" from the dropdown, and keep the folder as "/ (root)".

4. Click the "Save" button.

5. Wait about 1-2 minutes. Refresh the page. You will see a link at the top (e.g., https://nathaniel-owusu.github.io/mission-hope-ghana/).

6. Click that link to view your site!
